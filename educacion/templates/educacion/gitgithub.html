1. ¿Qué es Git y GitHub?

Git es un sistema de control de versiones distribuido diseñado para rastrear cambios en el código fuente durante el desarrollo de software.

GitHub es una plataforma basada en la nube que permite alojar repositorios Git, facilitando la colaboración en proyectos de código abierto o privados.

Diferencia clave: Git es la herramienta local de terminal; GitHub es el servicio web remoto donde compartes tus repositorios.

2. Instalación y Configuración

Tras instalar Git en tu sistema operativo, configura tu nombre de usuario y correo global en la consola:

git config --global user.name "Tu Nombre"
git config --global user.email "tu_email@ejemplo.com"

3. Comandos Esenciales de Git

Comando Descripción
git init Inicializa un nuevo repositorio Git en el directorio actual.
git status Muestra el estado de los archivos (modificados, rastreados o no).
git add . Agrega todos los archivos modificados al área de preparación (Staging Area).
git commit -m "mensaje" Guarda una foto (snapshot) del proyecto con un mensaje descriptivo.
git push origin main Envía las confirmaciones locales al repositorio remoto en GitHub.

4. Flujo de Trabajo en GitHub

  1. Fork o Crear Repositorio: Crea tu proyecto en GitHub o clona uno existente.
  2. Crear Ramas (Branches): Trabaja en nuevas funcionalidades en ramas independientes con git checkout -b nueva-rama.
  3. Pull Requests (PR): Solicita la integración de tu código revisado a la rama principal.
