1. ¿Qué es HTML?

HTML son las siglas de HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Es el estándar encargado de estructurar y organizar el contenido de una página web.

Nota importante: HTML NO es un lenguaje de programación. No maneja lógica condicional ni matemáticas; es un lenguaje de etiquetas de marcado.
Funciones principales de HTML:
  • Organiza el contenido de la web.
  • Define títulos, subtítulos y párrafos.
  • Permite insertar imágenes y multimedia.
  • Crea hipervínculos (enlaces) entre documentos.

2. Estructura Básica de un Documento HTML

Todo sitio web moderno comienza con un código base imprescindible. A continuación se presenta el esqueleto estándar:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>
</head>
<body>
    <h1>¡Hola Mundo!</h1>
    <p>Esta es mi primera página web estructurada.</p>
</body>
</html>
Explicación paso a paso de cada línea:
Línea / Etiqueta Explicación
<!DOCTYPE html> Indica al navegador que el documento utiliza el estándar HTML5.
<html lang="es"> Etiqueta raíz que envuelve todo el sitio. El atributo lang="es" define el idioma principal en español.
<head> Contenedor de metadatos (configuraciones, scripts, títulos) que no se ven directamente en la página.
<body> Contiene todo el contenido visible del sitio web (textos, imágenes, enlaces, botones).

3. La Etiqueta <head> y sus Metadatos

Las etiquetas dentro de <head> le otorgan instrucciones técnicas al navegador y a los motores de búsqueda:

Etiqueta Función Principal
<title> Establece el texto que aparece en la pestaña del navegador.
<meta charset="UTF-8"> Asegura la codificación de caracteres especiales como eñes (ñ) y acentos (á, é, í, ó, ú).
<meta name="viewport" ...> Garantiza el correcto escalado del diseño en pantallas móviles (responsive design).

4. Etiquetas de Texto Fundamentales

Etiqueta Uso
<h1> a <h6> Títulos y subtítulos con jerarquía (donde <h1> es el de mayor relevancia).
<p> Define párrafos de texto.
<strong> Aplica importancia semántica y texto en negrita.
<em> Aplica énfasis y estilo de cursiva.
